# Playlog

Una app para descubrir videojuegos: ves los que están en tendencia, exploras el catálogo y guardas los tuyos en tu biblioteca.
Es el proyecto del equipo Chicharrón (Marc y Jie) en DAM 2026-27: la referencia de Playlog (HTML, CSS y JavaScript), hecha en React sprint a sprint.

## Cómo arrancarla

```bash
npm install
npm run dev
```

Y abrid la dirección que aparece (con las herramientas de desarrollo en modo móvil).

## Carpetas

| Carpeta | Qué hay |
|---|---|
| `src/components` | Los componentes (átomos, moléculas y organismos) |
| `src/pages` | Una pantalla por fichero |
| `src/data` | Los datos de ejemplo |
| `src/utils` | Las funciones puras: filtrar, ordenar, calcular |
| `docs` | El modelo de datos y los componentes de cada pantalla |

## Cómo trabajamos

Cada tarjeta de Trello es una rama (`s1-vite`, `s1-carpetas`, `s1-datos`…), que entra en `main` con un Pull Request revisado por la otra persona del equipo.
